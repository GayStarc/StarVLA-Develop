# 更新说明：手动步进控制功能

> **更新日期**: 2024-02-07  
> **功能**: 为StarVLA推理脚本添加手动步进控制模式

## 🎯 更新内容

### 主要变更

1. **移除任务完成自动检测**
   - 不再自动判断任务是否完成
   - 由用户手动控制推理的每一步
   - 达到最大步数后自动停止

2. **新增手动步进模式**
   - 添加 `--manual-step` 参数
   - 每步执行前暂停并等待用户确认
   - 显示完整的机械臂状态和输出动作

3. **增强状态显示**
   - 详细的左右臂位置（xyz坐标）
   - 详细的左右臂姿态（欧拉角，弧度和角度）
   - 夹爪状态（数值和开/闭状态）
   - 动作增量和幅度
   - 推理耗时

4. **灵活的控制选项**
   - 单步执行（Enter/n）
   - 连续执行N步（s N）
   - 切换到自动模式（c）
   - 安全退出（q或Ctrl+C）

## 📝 使用方法

### 启动手动模式

```bash
python starvla_r1lite_inference.py --task "你的任务" --manual-step
```

### 控制命令

| 命令 | 功能 |
|------|------|
| `Enter` 或 `n` | 执行下一步 |
| `c` | 切换到连续模式 |
| `s N` | 跳过N步（如 `s 10`）|
| `q` | 退出推理 |
| `Ctrl+C` | 紧急停止 |

## 🎓 使用场景

### 场景1：首次测试新任务

```bash
# 使用手动模式逐步验证
python starvla_r1lite_inference.py \
    --task "新任务" \
    --manual-step \
    --max-steps 50

# 每一步检查动作是否合理
# 发现问题可随时退出
```

### 场景2：调试特定阶段

```bash
# 手动执行前5步观察初始阶段
按Enter × 5

# 跳过接近阶段
输入: s 20

# 仔细观察关键动作
按Enter × 5

# 切换到连续模式完成
输入: c
```

### 场景3：学习和分析

```bash
# 手动模式运行完整任务
python starvla_r1lite_inference.py \
    --task "学习任务" \
    --manual-step \
    --log-dir logs/learning

# 每一步：
# 1. 观察当前状态
# 2. 预测合理的动作
# 3. 对比模型输出
# 4. 学习模型决策
```

## ⚠️ 注意事项

### 与自动模式的区别

| 特性 | 自动模式 | 手动模式 |
|------|----------|----------|
| 启动参数 | 无需额外参数 | `--manual-step` |
| 执行方式 | 连续自动 | 逐步确认 |
| 输出详细度 | 简化 | 完整 |
| 任务完成检测 | ❌ 已移除 | ❌ 已移除 |
| 适用场景 | 成熟任务 | 调试/学习 |

### 安全建议

1. **首次使用务必用手动模式**
   - 可以及时发现异常
   - 避免意外碰撞

2. **观察动作幅度**
   - 正常: < 0.01 (1cm)
   - 警惕: > 0.05 (5cm)
   - 异常: > 0.1 (10cm)

3. **检查位置范围**
   - 确保在工作空间内
   - 参考初始位置判断

4. **随时准备停止**
   - 保持手在键盘上
   - 急停按钮触手可及
