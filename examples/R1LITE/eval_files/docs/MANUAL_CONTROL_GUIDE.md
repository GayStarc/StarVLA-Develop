# 手动步进控制使用指南

## 功能说明

手动步进模式允许你逐步控制推理过程，每一步都会：
1. 显示详细的机械臂当前状态（位置、姿态、夹爪）
2. 显示模型输出的动作（增量和目标值）
3. 等待你的确认后才执行动作
4. 可以在任何时候切换到连续模式或退出

## 使用方法

### 启动手动步进模式

```bash
# 基础使用
python starvla_r1lite_inference.py --task "拿起红色方块" --manual-step

# 完整参数
python starvla_r1lite_inference.py \
    --task "Pick up the red cube" \
    --config deploy_policy.yml \
    --max-steps 300 \
    --manual-step \
    --log-dir logs/manual_test
```

### 启动自动模式（原模式）

```bash
python starvla_r1lite_inference.py --task "拿起红色方块"
```

## 控制命令

在手动步进模式下，每执行完一步推理后，会显示控制选项：

```
【控制选项】
  [Enter/n] 执行下一步
  [c]       切换到连续模式
  [s N]     跳过N步（例如: s 10）
  [q]       退出推理
```

### 命令详解

| 命令 | 说明 | 示例 |
|------|------|------|
| **Enter** 或 **n** | 执行下一步推理并等待下次确认 | 直接按回车 |
| **c** | 切换到连续模式，后续自动执行 | 输入 `c` 后回车 |
| **s N** | 连续执行N步后再次暂停 | `s 10` 执行10步 |
| **q** | 安全退出推理 | 输入 `q` 后回车 |
| **Ctrl+C** | 紧急停止（任何时候都可以） | - |

## 输出信息说明

每一步会显示如下详细信息：

### 推理信息
```
步骤 000
================================================================================
推理耗时: 45.2ms
```

### 左臂/右臂状态
```
【左臂状态】
  位置 (xyz):  [+0.0590, -0.3320, +0.3430] 米
  姿态 (rpy):  [+0.0000, +0.0000, +0.0000] 弧度
               [+0.00°, +0.00°, +0.00°]
  夹爪状态:    0.00 [打开]
```

**说明**：
- **位置 (xyz)**: 末端执行器在基座标系下的位置（米）
  - x: 前后方向（正值向前）
  - y: 左右方向（正值向左）
  - z: 上下方向（正值向上）
- **姿态 (rpy)**: Roll-Pitch-Yaw 欧拉角
  - Roll: 绕x轴旋转
  - Pitch: 绕y轴旋转
  - Yaw: 绕z轴旋转
- **夹爪状态**: 0.0=完全打开，1.0=完全闭合

### 左臂/右臂动作
```
【左臂动作】
  位置增量:    [+0.00120, -0.00030, +0.00050] 米
  姿态增量:    [+0.00000, +0.00000, +0.00000] 弧度
               [+0.000°, +0.000°, +0.000°]
  夹爪目标:    0.00 [打开]
  动作幅度:    0.00130
```

**说明**：
- **位置增量**: 相对于当前位置的移动量（delta）
- **姿态增量**: 相对于当前姿态的旋转量（delta）
- **夹爪目标**: 目标夹爪状态（0.0-1.0）
- **动作幅度**: 位置和姿态增量的综合大小

## 使用场景

### 场景1：调试和验证

```bash
# 启动手动模式
python starvla_r1lite_inference.py --task "测试任务" --manual-step --max-steps 50

# 每一步：
# 1. 检查机械臂当前位置是否正确
# 2. 检查输出动作是否合理
# 3. 按Enter执行
# 4. 观察机械臂运动
# 5. 重复
```

### 场景2：观察特定阶段

```bash
# 启动手动模式
python starvla_r1lite_inference.py --task "抓取物体" --manual-step

# 前几步手动观察
按Enter × 5次

# 看起来正常，跳过接近阶段
输入: s 20

# 到达抓取点，切换回手动
等待20步后自动暂停

# 仔细观察抓取动作
按Enter × 3次

# 抓取完成，切换到连续模式
输入: c
```

### 场景3：安全测试

```bash
# 首次测试新任务，使用手动模式
python starvla_r1lite_inference.py \
    --task "新任务" \
    --manual-step \
    --max-steps 100

# 每一步检查：
# 1. 动作幅度是否过大（action magnitude）
# 2. 位置是否在安全范围内
# 3. 如果异常，立即按 q 退出
```

## 注意事项

### ⚠️ 安全提示

1. **首次使用务必使用手动模式**
   - 可以及时发现异常动作
   - 避免机械臂意外碰撞

2. **观察动作幅度**
   - 正常情况：动作幅度 < 0.01（1cm）
   - 如果动作幅度 > 0.05（5cm），需谨慎
   - 异常大的动作可能导致快速运动

3. **检查位置范围**
   - 确保xyz坐标在安全工作空间内
   - 参考初始位置进行判断

4. **随时准备急停**
   - 保持手放在键盘上（按 q 或 Ctrl+C）
   - 确保急停按钮触手可及

### 💡 使用技巧

1. **组合使用命令**
   - 初期：手动模式（逐步检查）
   - 中期：跳过模式（s N，快速通过）
   - 后期：连续模式（c，自动完成）

2. **查看日志**
   - 所有输出都会保存到日志目录
   - 可以事后分析每一步的状态和动作

3. **分段测试**
   - 不需要一次完成整个任务
   - 可以在关键步骤退出（q）
   - 下次从安全位置重新开始

## 对比：自动模式 vs 手动模式

| 特性 | 自动模式 | 手动模式 |
|------|----------|----------|
| 执行方式 | 连续自动 | 逐步确认 |
| 输出详细度 | 简化（每10步） | 完整（每一步） |
| 适用场景 | 成熟任务、批量测试 | 调试、首次运行、学习 |
| 控制灵活性 | 仅Ctrl+C | 多种命令 |
| 推理速度 | 按设定频率运行 | 取决于用户操作 |
| 安全性 | 依赖预设检查 | 人工监督每一步 |

## 常见问题

### Q1: 手动模式下如何加快速度？

**A**: 使用跳过命令
```
# 一次跳过10步
请输入命令: s 10

# 或直接切换到连续模式
请输入命令: c
```

### Q2: 如何在连续模式下暂停？

**A**: 连续模式无法中途暂停，只能：
- 按 Ctrl+C 完全停止
- 下次启动时使用手动模式

### Q3: 输出信息太多，如何精简？

**A**: 使用自动模式（不加 `--manual-step`），输出会自动精简到每10步。

### Q4: 可以保存每一步的截图吗？

**A**: 当前版本不支持自动截图，但你可以：
- 在暂停时手动截图
- 查看日志文件中的数值记录
- 后续版本会考虑添加此功能

### Q5: 手动模式下机械臂会一直等待吗？

**A**: 是的，在手动模式下：
- 完成当前步后，机械臂会停留在当前位置
- 等待你输入命令
- 不会因超时而自动执行或复位

### 结合日志分析

```bash

    --task "复杂任务" \
    --manual-step \
```

### 自定义退出条件

修改 `starvla_r1lite_inference.py` 中的 `wait_for_user_input()` 方法，添加自定义命令：

```python
elif user_input == 'save':
    # 保存当前状态
    return 'save_state'
elif user_input == 'reset':
    # 重置到初始位置
    return 'reset_pose'
```
